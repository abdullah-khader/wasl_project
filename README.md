# وَصْل

مشروع React بسيط لمحاكاة إعارة الكتب الإلكترونية بين المكتبات الجامعية، مع توثيق عمليات الإعارة في كتل مترابطة باستخدام SHA-256.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط الذي يظهر في الطرفية، وغالبًا يكون `http://localhost:5173`.

## تجربة المشروع

1. اختر الجامعة المستفيدة.
2. سجّل إعارة كتاب من جامعة أخرى.
3. اضغط «فحص السلسلة» للتحقق من سلامة الكتل.
4. اضغط «تجربة التلاعب» لتغيير بيانات إعارة سابقة واكتشاف الاختلاف.
5. اضغط «إعادة ضبط» لبدء تجربة جديدة.

المشروع نموذج تعليمي يعمل داخل المتصفح. سجلات الإعارة لا تُحفظ بعد تحديث الصفحة، ولا توجد شبكة موزعة حقيقية أو ربط بالمكتبات أو تراخيص الناشرين.
